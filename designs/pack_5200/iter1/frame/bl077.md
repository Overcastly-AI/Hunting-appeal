## 9. Assumptions

- ASSUMPTION B-BASIS-N5: The Bambu TDS +/- values are standard deviations of an ISO 527 set of n 5 (the ISO 527-1 minimum; the TDS gives no n): B-basis k 3.4066 on the lower published mean of each property. Settled by: CA-3-PAHT at n 10.
- ASSUMPTION WET-PAHT: Wet / dry = 0.82 XY (Bambu's 12-18 % decline, the 18 % floor; the XY bending pair reads 0.92) and 0.80 Z (the Z bending pair 49 / 61): bending pairs stand in for tensile. Settled by: CA-3-PAHT hot/wet vs dry.
- ASSUMPTION HOT-40-PAHT: 40 C / 23 C = 0.82 from the Fiberlogy PA12 CF15 UTS curve (Ciganas 2026), the lowest of the direct and two Tg-shift readings; a PA12-CF15 grade stands in for PAHT-CF. Settled by: CA-3-PAHT at 40 C.
- ASSUMPTION TAU-VM: Interlayer shear allowable = Z / sqrt 3 (von Mises), was 0.6 x Z with no source; the frame code's 0.6 x s_z rule is fed s_z = tau / 0.6, so the layer-normal term reads 3.8 % harsh. Settled by: CA-3-PAHT SBS.
- ASSUMPTION E-WET: Hot/wet modulus = 0.716 (Ciganas E 40 / 23 C) x 0.82 (wet strength ratio) = 0.587; buckling rows are scaled by 0.587 / 0.6 from the booked basis. Settled by: CA-4-PAHT.
- ASSUMPTION FAT-0.30: PAHT fatigue at 1e5 = 0.30 x the hot/wet B-basis static strength (record ratio, unchanged). Settled by: CA-1-PAHT.
- ASSUMPTION PERFECT-LOCAL: The bound on any local fix removes the hot-spot regions from the utilisation population and assumes nothing else changes (a real doubler also attracts load: the bound is optimistic for it). Settled by: not needed: the bound already fails.
