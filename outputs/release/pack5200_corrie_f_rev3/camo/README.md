## 1. Which camo and colourway
- **Pattern:** **Owner Base** (the owner's own 4-ink SVG; primary camo since DECISIONS 2026-11-01).
- **Scale:** **accent repeat 380 x 380 mm (14.96 in)**, upright (the streaks run vertically on the bag). This is what
  the rev 3 renders use (`huntkit/viz3d`, `camo_repeat_mm` 380). The 760 mm full-scale file is included as an
  option for B-02u (owner_base.yaml offers 760 on panels >= 250 mm: deer can resolve the blobs to about 50 m instead of
  about 25 m). The layouts use 380.
- **Inks:** Bench Grass, Sidehill Olive, Bleached Tine, Deadfall Shadow (section 4).
- **Solids around the camo in the renders:** body #6E745B (Krummholz Sage), trim #2D2B27 (Basalt Ink), harness #4A4B3C
  (Spruce Shadow). Those come from a fallback: the renders ask for the colourway id `talus`, which only exists in
  the *alternate* (Cirquefall) section of `colorways.yaml`, so `viz3d.export.colorway()` falls back to its hard-coded
  defaults. **Owner decision:** keep that look, or name a primary pairing (Sidehill or Wallow; see
  `previews/camo_bag_mock.png`). The print does not change either way.

## 3. Print files (`print/`)

All files are sRGB 8-bit, **300 dpi at 100 %**, 4 flat inks plus unprinted white. In the placed files each piece
is printed in its own on-bag frame (art upright on the bag), with 3 mm bleed past a grey cut line, its ID inside
the seam allowance, and an ink QC strip plus a 100 mm test square in the waste. `*_cut.svg` gives the cut contours in
the same frame (mm) for a contour cutter. `placement.csv` lists every piece's position, rotation and camo
phase.

| File | Size | Use |
|---|---|---|
| `owner_base_accent_380mm_300dpi.png` / `.tif` | 4488 px square = 380 mm | uniform seamless repeat ("basic repeat" at any bureau or mill) |
| `owner_base_full_760mm_300dpi.tif` | 8976 px square = 760 mm | option: full scale |
| `corrie_f_rev3_camo_hyperd300_1yd_2sets_ab1_300dpi.png` | 58 x 36 in, 1.2 MB | **first order:** RBTR HyperD 300, 1 yd = 2 bag sets + the BL-038 AB-1 specimens (300 x 300 lab sample, 300 x 300 look/spare, 2 brush strips 50 x 300) |
| `corrie_f_rev3_camo_hyperd300_1yd_3sets_300dpi.png` | 58 x 36 in, 1.1 MB | RBTR HyperD 300, 1 yd = 3 bag sets |
| `corrie_f_rev3_camo_630d_engineered_repeat_3sets_300dpi.tif` | 1500 x 762 mm | 630D mill run: an engineered straight repeat of 3 sets down the roll |
| `corrie_f_rev3_camo_1set_tile_300dpi.png` | 438 x 868 mm | one set, for area-billed print-on-demand |

**How to order at RBTR (Design Your Own, HyperD 300):** upload the 58 x 36 in PNG as one full linear yard at 100 %,
not as a repeat (ASSUMPTION RBTR-FULLYARD: their tool accepts a full-yard image; check the preview shows one copy,
not tiles). For several yards, order each yard as its own 1 yd item with the same file. Order the $5 8 x 8 in sample of
`owner_base_accent_380mm_300dpi.png` first if you want a colour check before the yard.

**Cutting:** lay the print face up and cut on the grey line. Notches and drill marks come from the paper pattern or
DXF (`../patterns/`): lay the pattern on the print and match the cut line. The grain runs down the roll (the image
vertical) for every piece. B-29f lies across its own art on the cloth, which is intended: its art is drawn in its
own frame.

## 4. Colour specification (`colour_spec.csv`)

Names and HA codes are our own TCX-style identifiers, not Pantone numbers. Lab is CIELAB D65 computed from the sRGB
targets; measure strike-offs at D65/10 deg.

| Ink | Name (code) | Hex | sRGB | L* a* b* | deer-sim L* | share on the pieces |
|---|---|---|---|---|---|---|
| 1 | Bench Grass (HA 15-1114) | #AE9D6C | 174 157 108 | 65.1 -1.0 27.9 | 64.4 | 33.3 % |
| 2 | Sidehill Olive (HA 17-0830) | #8B8148 | 139 129 72 | 53.7 -4.5 32.1 | 53.2 | 29.8 % |
| 3 | Bleached Tine (HA 13-1008) | #C6B497 | 198 180 151 | 74.1 1.8 17.2 | 73.4 | 7.2 % |
| 4 | Deadfall Shadow (HA 19-0510) | #313120 | 49 49 32 | 19.9 -3.4 10.9 | 19.9 | 29.8 % |

- **Tolerances:** production (mill strike-off) ΔE00 <= 1.0 per ink (owner_base.yaml `qc`); dark ink |ΔL*| <= 0.7.
  ASSUMPTION TOL-PROTO: print-on-demand prototypes are accepted at ΔE00 <= 3.0 per ink, because digital POD lots are
  not colour-held. Measure the QC strip on the sheet.
- **No optical brighteners** in the base or the inks. Check the white base and the light inks under a 365 nm lamp:
  any blue glow fails, since deer see UV. RBTR does not state whether its white base is OBA-free (record note), so the
  first yard is also that test.
- Hold olive and tan chroma to the low side on lab dips.

## 6. Fabric use (review: the 630D 10-bag marker is only 47 % efficient)

The U of B-02u is a 300 x 640 mm hole, so the other 8 pieces of a set **nest inside it** (`set_tile`). One set fits
in a 418 x 738 mm tile at **65 %** use.

| Layout | Length | Sets | m per set | Use |
|---|---|---|---|---|
| release 1-bag marker (uniform print) | 0.738 m x 1.45 m | 1 | 0.738 | 19 % |
| release 10-bag marker (uniform print) | 2.961 m | 10 | 0.296 | 47 % |
| placed 630D engineered repeat | 0.762 m repeat | 3 | **0.254** | 55 % of usable width |
| placed HyperD 1 yd | 0.914 m | 3 | 0.305 | 46 % |
| placed HyperD 1 yd + AB-1 | 0.914 m | 2 + tests | - | - |

Honest reading: the width (3 tiles across, a 160-185 mm strip left over) limits everything. For exactly 10 bags the
placed 630D run is 3.05 m against the marker's 2.96 m, but it yields **12 sets**. The saving is real per set
(-14 %) and at prototype scale: one yard makes 3 sets instead of 1. Use the 2 spare sets for repairs and destructive
seam tests. The placed print also removes the "one-way print" restriction: the art is drawn per piece, so 180 deg
on the marker is allowed.

## 8. Originality
See `originality_check.md`. In short: Owner Base is owner-supplied artwork. It shares the macro + pixel-micro
*concept* with Sitka Optifade and the pixel concept with MARPAT. Concepts are not what copyright protects; the
arrangement is. The image-level copy check is calibrated (copy 0.96, look-alike 0.27, other pattern 0.16) but has
**not** been run against commercial swatches, because the repo holds none. The owner must sign the provenance line
and run the swatch check before production.
