# CORRIE F rev 3 (door D2) - 5200 cu in hunting pack bag: sewing operation sequence

Beginner rules: all flat work before the bag becomes 3D; clips, never pins, in coated fabric; sew a swatch of the exact stack before every new operation; every load point is sewn only after its proof test passes (qc_sheet.md). Machines, needles and seams: tech pack section 2.


## Step 0 Prep and cutting

**0.01 Print and check the test square**
- How: Print patterns/print_letter/00_PRINT_FIRST_test_square.pdf at 100 %. The solid square must read 100 mm (+/- 1 mm) both ways, the dashed one 4 in. Do not cut from a wrong-scale print.
- Machine bench; needle -; thread -; SPI -; stitch -; seam -
- QC QC-01; beginner 0.10 h, SAM 0.0 min (one-off)
**0.02 Machine set-up and stack swatches**
- How: Make a 150 x 150 mm swatch of each stack and set tension until the lock sits mid-stack on both faces: (a) ULTRA + 330D body seam, tex 90 / Nm 110 R, 8 SPI; (b) Hypalon on ULTRA, double row; (c) 25 mm box-X tex 135 / Nm 140 R, 7 SPI; (d) 70D / mesh at 10 SPI. Keep them in the QC folder.
- Machine WF1; needle Nm 110/18 DPx17, round point R; thread bonded_nylon_tex90; SPI 8; stitch 301; seam SSa2, LSd, BOX, SSa (swatches)
- sketch SK-1, SK-2; QC QC-05, QC-06; beginner 1.00 h, SAM 0.0 min (one-off)
**0.03 Sew the first-article load samples**
- How: Before cutting the bag, sew the proof specimens exactly as the bag: 10 x 25 mm box-X loops + 2 IMC cam tabs (MT-1), 5 T3 tongues on 70 mm B-17 tabs on B-01 swatches (PT-2), 1 hinge eye for the HE-FIT dry fit on a printed z 60 fairlead FIRST, then 5 hinge eyes exactly as op 4.05 and SK-8 in its order (B-18 rows first through B-18 + B-01 only; then HE folded in half, eye UP, box-X 34 x 7 through HE + B-01 + B-18 below the cheek line; B-18 and both HE raw ends caught in a B-01 | B-05 SSa2 floor seam sewn with the zipper / edge foot, no binding: PT-3), 5 B-24 links (PT-6), 5 TL-1 sleeves (38 mm B-25) on real crown bar stock. The bag's load points are sewn only after these pass.
- Machine BT / PS (prototype WF2 + J1); needle Nm 140/22 DPx17, round point R; thread bonded_nylon_tex135; SPI 7; stitch 301 box-X path; seam BOX + LSd (as the bag)
- load table: all load points; sketch SK-1; QC TEST gates; beginner 3.00 h, SAM 0.0 min (one-off)
**0.04 Cut 77 fabric / sheet pieces**
- How: Per cutting_plan.csv: lay face up (one way for camo and mesh), L+R pieces face to face, cut windows, slots and slits FIRST, knife clockwise from the grain arrow. Notches 6 mm, never past the seam line. Hypalon, TPU-840D and HDPE from the DXF on the laser / router.
- Machine SK / LASER / HK; needle -; thread -; SPI -; stitch -; seam -
- QC QC-02, QC-03, QC-04; beginner 9.24 h, SAM 66.5 min
**0.05 Hot-knife 78 webbing / elastic / cord pieces**
- How: Cut lengths in cutting_plan.csv (crown kit M shown; B-28 and W3 per crown kit). Use the J8 stop; seal both ends; no hard bead wider than the webbing.
