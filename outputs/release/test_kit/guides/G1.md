# G1: Order the long-lead parts, print and condition the coupons

**When:** week 1, day 1  
**Rig:** 3D printer (frame profile), oven, conditioning box (kit D)  
**Kits:** B (filament), D

Start here, today. The frame coupons need 7 days in the conditioning box before the lever rig can test them, so they set the pace for frame release R1. Order the long-lead parts the same day.

## Safety (read before you start)

- Hot oven and hot nozzle: gloves. Magnesium nitrate is an oxidizer and an irritant: gloves, keep it away from heat sources and children, label the box.

## Rig sketch

```
dry the spool -> print (frame profile, same job as a frame half) -> anneal 90 C 6 h -> cool in the oven
-> conditioning box (saturated magnesium nitrate, ~53 % RH) 7 days -> lever rig (G4)
```

Steps:

1. Dry the spool. Print with the frame profile (`designs/pack_5200/print/frame_h1/BUILD_H1.md` section 3): 0.6 mm hardened nozzle, 290 C, bed 100 C, 0.20 mm layers, 6 walls, 100 % infill. The flat bars need no supports. The frame-cut pieces (IM3-EC coupons, the CLEVIS-SHARE route piece) DO: SUPPORTS REQUIRED (it touches the plate over only about 10 mm2, 79 % overhangs more than 45 deg, review 5 B-1): tree supports FROM THE BUILD PLATE under the whole piece, in PAHT-CF, top Z distance 0.20-0.25 mm, 2-3 interface layers, 45 deg threshold, support blockers painted inside every bore, pin hole, bolt hole, counterbore and nut trap. After printing break the supports off, sand the scars flush ALONG the stay ([PLACEHOLDER BL-053] per-piece orientation and supports: check BUILD_H1 section 10 first). The US2 clevis prints flat with no supports. The CA-5 joint stubs and the T7 sleeve segment: turn on the same tree supports if the slicer's overhang view shows red under them (BL-054).
2. XY bars lie flat on their 10 mm face (4 mm is the print height), like the frame.
3. Anneal 90 C for 6 h on a flat plate; cool in the oven.
4. Into the conditioning box for **7 days** (23 C, about 53 % RH). Write the date on the box.
5. Measure each bar's gauge width and thickness at 3 points with the caliper; write the smallest on the bar.
