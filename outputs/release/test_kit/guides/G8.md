# G8: PPA-CF frame path (H1-P): coupons first, then the gate

**When:** only if you build the PPA-CF frame; start the day the PPA-CF spools and the 120 C dryer arrive  
**Rig:** H2S (PPA-CF profile), 120 C dryer, 50 C salt conditioning jar, 0.001 g scale, kit B lever rig (100 kg cell), short-beam jig, 3-point fixture, 40 C box, chest freezer  
**Kits:** B, A, D

The PPA-CF H1-P frame (BL-073 p3) is printed only after the BL-073 coupons, the US2 lug proof and CLEVIS-SHARE-B-PPA pass. Print the first-article upper half first, then the coupon jobs, each beside its dummy tower. T4b/T4c-PPA-COLD run on the P1 frame later. The PAHT-CF H1 (G1 to G7) stays the fallback. Full sheets, print plan and pictures: `designs/pack_5200/print/frame_h1p/COUPONS_H1P.md` (also in `outputs/release/frame_h1p_ppa/`).

About **39.0 h** hands-on and **563 h** of machine time.

## Safety (read before you start)

- The 120 C dryer, the 50 C jar and the 110 C bed burn: gloves. PPA-CF dust from sawing and sanding the blocks: mask and glasses, vacuum not compressed air.
- Every static pull stays under the 100 kg cell (max about 821 N, the dry short-beam bars): blanket over the rig, stand to the side.
- -20 C parts are brittle and can shatter: glasses and gloves for every drop; the T4b-PPA-COLD frame drop is loaded to 68 kg: nobody's feet under it.

```

-> GATE (coupons + lug proof + share) -> H1-P halves -> P1: T4b-PPA-COLD, T4c-PPA-COLD
```

## 1. FA-H1P-UP: First-article H1-P upper half (PPA-CF): snap-off pads, planned filament change, layer time

**Specimen:** `designs/pack_5200/iter1/frame/h1p/h1_upper_flat_print.stl`, spools 1 + 2

**Steps**

1. Dry spools 1 and 2 at 120 C (248 F) for 10 h (PRINT_SHEET_H2S.md). Spool 1 must be FULL.
2. Slice `designs/pack_5200/iter1/frame/h1p/h1_upper_flat_print.stl` (the part with its 6 snap-off pads) with the settings of PRINT_SHEET_H2S.md section 1. Do not rotate it.
3. Add the planned filament change (PRINT_SHEET_H2S.md section 3): Add Pause at layer 101 (print z 30.15 mm, 1.19 in). Screenshot the layer-time view and write the shortest and the median layer time.
4. Print. Stay at the printer for the first layer: all 6 pad feet and the brim stuck flat.

6. When done and below 40 C (104 F) in the chamber: feeler gauge under each pad foot and the brim edge: write the largest gap (pass <= 0.5 mm, 0.02 in).
7. Snap the pads off with flush cutters at the neck; sand each scar flush (no dent deeper than 0.6 mm, 0.024 in). Supports off as BUILD_H1 section 4.

9. Look at the change layer with the 10x loupe all round: write any gap, blob or line you can catch a fingernail on. Photograph it.

**Pass:** every pad and the brim stay down (gap <= 0.5 mm); pads snap off, scars sanded <= 0.6 mm; spool change at layer 101 done within 10 min; filament within 10 % of 833 g; shortest and median layer time written; mass of the half -3 / +4 % of the export

## 2. CA-3-HW: PPA-CF Z tensile + SBS, hot/wet B-basis at n 10, dry set, pause-layer SBS

**Why:** H1-P frame print (BUILD_H1P gate (a) the BL-073 coupons pass: CA-3-HW, CA-1-HW, CA-4-HW (a), T4c-PPA-HW and T4c-PPA-CROWN; (b) US2-LUG-PPA, the US2 lug proof at x 1.08 load, passes; (c) CLEVIS-SHARE-B-PPA measures an outer-cheek share <= 0.79)  
**Specimen:** hot/wet: 10 Z + 10 SBS; dry: 6 Z + 6 SBS; pause-layer: 6 SBS (hot/wet); Z bars ISO 527-2 1BA cut from the Z slab (job C), SBS bars from the blocks (job A, job B)

**Steps**

1. Print job A, job B and job C (COUPONS_H1P.md section 2). Every coupon job prints beside its dummy tower (`test_pieces/tower_<job>.stl`) so every layer takes >= 181 s: check the slicer preview's layer-time view and write the shortest layer time of each job.
2. SBS block: sand 0.3 mm off the top and the bottom on 240-grit paper glued to glass (3.6 -> 3 mm, 0.118 in), so the mid-plane stays on the line between layers 6 and 7. Saw the bars 18 x 6 mm on the pencil grid with a fine-tooth saw, trim the 5 mm edge strip off first.
3. Z slab: trim 2.5 mm off each end, saw it into 12 mm strips, file each to the ISO 527-2 1BA outline with the filing template (gauge 5 mm wide), sand both faces to 2 mm (0.079 in). The gauge crosses the layers.
4. Label with a paint pen: CA3-Z-H1..H10 and CA3-S-H1..H10 (hot/wet), CA3-Z-D1..D6 and CA3-S-D1..D6 (dry), CA3-P1..P6 (pause block B).
5. DRY set: sealed in a zip bag with desiccant; test within 24 h at 23 C (73 F).
6. CONDITION: tray of non-iodised salt (NaCl) wetted to a slush in a sealed glass jar, parts on a rack above it, jar in the box at 50 C (122 F) (74.4 % RH over the salt). Weigh the traveller plate on the 0.001 g scale every day at the same hour; done when it changes < 0.1 % in 24 h. Write the uptake % (TDS: 1.3 %). The hot/wet Z and SBS bars and the pause bars go in together.
7. Test at 40 +/- 2 C (104 F) inside the 40 C box, 1 h soak first, thermometer beside the part.
8. Z tensile: lever rig static (turnbuckle in place of the spring). Strength = peak cell force x 4 / (width x thickness). Dry bars need about 570 N (58.1 kg on the scale, 128 lbf) at the bar, under the 100 kg cell.
9. Short-beam shear: jig with the D6 loading pin on top and two D3 supports 12 mm (0.47 in) apart, bar flat as printed. Load slowly to the drop. Shear strength = 0.75 x F_max / (width x thickness). Dry bars about 821 N (83.7 kg on the scale, 185 lbf).
10. Sheet formulas: B-basis of a set of 10 = AVERAGE - 2.355 x STDEV; of the 6 pause bars = AVERAGE - 3.0063 x STDEV. Type every value; send the sheet the same day.

**Pass:** (a) hot/wet Z B-basis (mean - 2.355 SD) >= 23.7 MPa; (b) hot/wet SBS B-basis >= 14.2 MPa; (c) pause-layer SBS mean >= 0.9 x the no-pause hot/wet SBS mean and its B-basis >= 14.2 MPa; (d) record: uptake, hot/wet / dry Z (booked 0.621). Below (a): R1 = 1.048 x Z_m / 24.8, z 234 joint fatigue = 1.072 x Z_m / 24.8; hold the build and grow the hot spot by the shortfall

**Write in the results sheet** (`results_template.csv`, column `measured`):

- `CA-3-HW-01 to CA-3-HW-10` (hot/wet 1 to hot/wet 10): Z tensile strength, hot/wet. Type the value in MPa.
- `CA-3-HW-11 to CA-3-HW-20` (hot/wet 1 to hot/wet 10): SBS strength, hot/wet. Type the value in MPa.
- `CA-3-HW-21 to CA-3-HW-26` (dry 1 to dry 6): Z tensile strength, dry. Type the value in MPa.
- `CA-3-HW-27 to CA-3-HW-32` (dry 1 to dry 6): SBS strength, dry. Type the value in MPa.
- `CA-3-HW-33 to CA-3-HW-38` (pause 1 to pause 6): SBS strength, pause. Type the value in MPa.
- `CA-3-HW-39` (hot/wet set): Z tensile B-basis (mean - 2.355 SD). MPa, pass if at least 23.7.
- `CA-3-HW-40` (hot/wet set): SBS B-basis (mean - 2.355 SD). MPa, pass if at least 14.2.

## 3. CA-1-HW: PPA-CF short-beam-shear fatigue at 40 C, conditioned, 1.15 x Smax

**Why:** H1-P frame print (BUILD_H1P gate (a) the BL-073 coupons pass: CA-3-HW, CA-1-HW, CA-4-HW (a), T4c-PPA-HW and T4c-PPA-CROWN; (b) US2-LUG-PPA, the US2 lug proof at x 1.08 load, passes; (c) CLEVIS-SHARE-B-PPA measures an outer-cheek share <= 0.79)  
**Specimen:** 6 SBS fatigue + 3 SBS static from the same block (the layer-normal share, 7 % of the R1 top 1 %, is covered by the CA-3-HW Z bars)

**Steps**

1. Bars from block A: CA1-F1..F6 (+1 spare) and CA1-S1..S3, faced, cut and labelled with the CA-3-HW bars; conditioned with the CA-3-HW hot/wet set.
2. Fit the short-beam jig at the coupon station of the lever rig and put the 40 C box round it (link through the slot in its lid, ASSUMPTION BOX-ON-RIG). Test at 40 +/- 2 C (104 F) inside the 40 C box, 1 h soak first, thermometer beside the part.
3. Measure each bar's width and thickness (caliper, 3 points, smallest). Static first: the 3 S bars to failure as CA-3-HW short-beam shear.
4. Fatigue peak for each bar: F_max = 5.52 MPa x width x thickness / 0.75 (about 132 N (13.5 kg on the scale, 30 lbf) at the bar, 3.4 kg on the cell); F_min = 0.1 x F_max (R 0.1).
5. Set the crank throw and the turnbuckle so the cell swings between F_min / 4 and F_max / 4; check over 20 slow turns by hand before the motor runs.
6. Run each bar to 100,000 cycles at 1 Hz (about 28 h; never above 5 Hz). The rig stops itself on a break, a stiffness drop over 10 % or a force drift over 5 %.
7. After each run-out: loupe on the bar's middle layer line, photograph, type the cycles reached. A bar that breaks: stop and send the sheet; never swap in the spare to make the count.

**Pass:** all 6 SBS bars run out to 100,000 cycles at Smax = 5.52 MPa (peak 132 N on the jig), R 0.1, 40 +/- 2 C; the 3 static SBS >= the CA-3-HW SBS line 14.2 MPa

**Write in the results sheet** (`results_template.csv`, column `measured`):

- `CA-1-HW-01 to CA-1-HW-03` (static 1 to static 3): SBS strength, hot/wet 40 C. MPa, pass if at least 14.2.
- `CA-1-HW-04 to CA-1-HW-09` (fatigue 1 to fatigue 6): cycles reached at Smax 5.52 MPa. Cycles, pass if at least 100000.
- `CA-1-HW-10` (40 C box): thermometer during the runs. C, pass if 38 to 42.

## 4. CA-4-HW: PPA-CF 3-point bend modulus at 23 C dry / 40 C conditioned / 60 C dry

**Why:** H1-P frame print (BUILD_H1P gate (a) the BL-073 coupons pass: CA-3-HW, CA-1-HW, CA-4-HW (a), T4c-PPA-HW and T4c-PPA-CROWN; (b) US2-LUG-PPA, the US2 lug proof at x 1.08 load, passes; (c) CLEVIS-SHARE-B-PPA measures an outer-cheek share <= 0.79) (row (a) only)  
**Specimen:** 5 XY bend bars 80 x 10 x 4 per condition (job D)

**Steps**

1. Bend bars from job D: 5 for 23 C dry, 5 for 40 C conditioned, 5 for 60 C dry (+1 spare). Label CA4-D, CA4-W, CA4-H.
2. The 23 C and 60 C sets stay sealed with desiccant. CONDITION: tray of non-iodised salt (NaCl) wetted to a slush in a sealed glass jar, parts on a rack above it, jar in the box at 50 C (122 F) (74.4 % RH over the salt). Weigh the traveller plate on the 0.001 g scale every day at the same hour; done when it changes < 0.1 % in 24 h. Write the uptake % (TDS: 1.3 %) (the 40 C set).
3. 3-point fixture: supports 64 mm (2.52 in) apart, bar flat as printed, dial indicator (0.01 mm) on top at mid-span.
4. Stiffness (each bar): hang 2.0 kg, zero the dial, add 5.0 kg (7.0 kg total), read the dial. E = span^3 x 49.0 N / (4 x width x thickness^3 x reading); the sheet does the sum.
5. Strength: load to the break with the come-along and the crane scale. Strength = 3 x F x span / (2 x width x thickness^2). Dry bars about 347 N (35.4 kg on the scale, 78 lbf).
6. 40 C set: tested at 40 +/- 2 C (104 F) in the 40 C box after 1 h. 60 C set: box thermostat at 60 C (140 F), thermometer 58-62 C for 30 min first (ASSUMPTION BOX-60).
7. Sheet: E ratio = mean E (40 C conditioned) / mean E (23 C dry); 60 C strength = AVERAGE - 3.41 x STDEV of the 5.

**Pass:** (a) E(40 C conditioned) / E(23 C dry), mean of 5, >= 0.5; (b) record: 60 C dry flexural strength mean - 3.41 SD >= 143 MPa

**Write in the results sheet** (`results_template.csv`, column `measured`):

- `CA-4-HW-01` (23 C dry): E mean. Type the value in MPa.
- `CA-4-HW-02` (40 C conditioned): E(40 C conditioned) / E(23 C dry). Ratio, pass if at least 0.5.
- `CA-4-HW-03` (60 C dry): flexural strength mean - 3.41 SD (record). Type the value in MPa.
- `CA-4-HW-04` (60 C box): thermometer reading during the 60 C tests. C, pass if 58 to 62.
