> **SAFETY HOLD (BL-078, 2026-11-25).** Do not carry the released PAHT-CF H1 frame with a load, and do not test it at or above its proof load (HA-LS-1 T1 (b) 300 lb / 136 kg, 2 x rated) or over it, until the PAHT coupons CA-3-PAHT, CA-1-PAHT and CA-4-PAHT report. Why: on the honest hot/wet basis BL-077 books the released H1 at strength 0.909 (goal 1) and cinch fatigue R1 0.481. Steps that load the frame below its proof level may still run; they are marked BELOW PROOF.

3. Run the sessions G2 to G7 in order. Each guide is one session, written for a phone. In G6 and G7 every test carries its SAFETY HOLD mark (BL-078). G8 is only for the PPA-CF frame (H1-P, BL-071), PARKED (cost, 2026-11-25).
4. Fill `results_template.csv` (columns `measured`, `date`, `photo`, `notes`) and send it after each session.

Frame release R1 needs, in order: CA-1 at **0.40** (3/3 run-outs), IM3-EC and CA-5 on the coupons; MT-1 on the bench; then on the first frames IM3-EP and W-PULL (P1), T9, T1, T2 and MT-1c (P2). R1 = CA-1 passes 0.40 with 3/3 run-outs AND MT-1c shows a cinch swing <= 117 % (peak-to-peak / mean) at a mean <= 150 N per anchor (structural countersign, adopted 2026-11-13, analysis/ca1_mt1c_confirm.md); if 0.40 fails: 3 XY bars at the table level for the measured swing, >= 0.313 (<= 0 %: 0.313 / <= 5 %: 0.316 / <= 10 %: 0.319 / <= 20 %: 0.325 / <= 30 %: 0.331 / <= 50 %: 0.345 / <= 70 %: 0.361 / <= 100 %: 0.386 / <= 115 %: 0.398). Swing > 115 %: STOP, no fallback level: the structural-fea-engineer re-runs the cinch case. The 0.276 / 0.404 levels are retired.

## Results sheet

`results_template.csv` has 705 rows over 103 tests. Each row says how it is judged (`check`: max, min, band, yes, record) against `limit`. Type numbers in the unit shown; type Y or N for yes/no rows. Do not change the other columns. Read back with:

```
python -m huntkit.manufacturing.test_results outputs/release/test_kit/results_template.csv --md report.md
```

It reports each test as PASS / FAIL / PARTIAL / OPEN, each release, and each ASSUMPTION as VERIFIED / FAILED / OPEN (`settles` column).
