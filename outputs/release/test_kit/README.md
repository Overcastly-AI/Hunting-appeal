## Start here

1. Read **G1** today: order the long-lead parts and print the frame coupons (they need 7 days).
2. Buy the rest from `shopping_list.md` (total **USD 2,343**).
3. Run the sessions G2 to G7 in order. Each guide is one session, written for a phone.
4. Fill `results_template.csv` (columns `measured`, `date`, `photo`, `notes`) and send it after each session.

## What gets released, in this order

**Frame release R1**: H1 print files released for load-carrying prints (DECISIONS BL-027: MT-1 cinch, CA-1, T1/T2 gauges; CA1 doc: with IM3-EC and CA-5).  
Tests: MT-1, CA-1, IM3-EC, CA-5, IM3-EP, W-PULL, T9, T1, T2, MT-1c

**Bag release, step 1: cut and sew**: every sewn load point and hardware item proven before the bag fabric is cut.  
Tests: PT-1, MT-2, MT-3, US-BS, PT-2, PT-3, PT-5, PT-6, LL-H, B-28 slip, PORT-1, TL-1, FS-O5, FRAY-1, WP-1

**Bag release, step 2: batch**: first-article bag checks before more bags are cut (release_tests.csv).  
Tests: WP-3, WP-2, T9-R3a, T9-R3c, T9-R3b, T9-R3d, GT-1, PT-7, WP-4, WP-5

**BL-037 weight gates**: the -119.1 g A_bl037 picks (weight_push.md).  
Tests: SL-1, CS-1, BP-1, AB-1, BU-1, HS-1, ST-1, HB-1, HB-D2

**Field release and the rest**: first loaded carry, meat haul, belt and comfort tests.  
Tests: HB-7, HB-6, CA-3, CA-4, HB-5, T6, T7, CA-2, HB-4, HB-T, PS-1, BP-2, HB-2, BP-3, RF-1, T3, CR-1, SP-1, T4a, T4b, T4c, T5, T5f, T2u, HB-3, HB-D1, HB-D3, FT-S2, MH-1, MH-2, MH-3, R28-1

Frame release R1 needs, in order: CA-1 at the release level **0.276** (governing flip 0.2556 + 0.02, from the BL-027 body and the 28 mm IM3 cheek; confirmed by BL-039), IM3-EC and CA-5 on the coupons; MT-1 on the bench; then on the first frames IM3-EP and W-PULL (P1), T9, T1, T2 and MT-1c (P2). MT-1c's measured cinch swing sets the CA-1 level R1 needs (BL-039): swing <= 0.4 %: 0.276; up to 70 %: the 0.40 pass as well; above: **0.404** (H1's fatigue with the cinch fully cycling is 0.782 against 1.175 static).

## Results sheet

`results_template.csv` has 223 rows over 76 tests. Each row says how it is judged (`check`: max, min, band, yes, record) against `limit`. Type numbers in the unit shown; type Y or N for yes/no rows. Do not change the other columns. Read back with:

```
python -m huntkit.manufacturing.test_results outputs/release/test_kit/results_template.csv --md report.md
```

It reports each test as PASS / FAIL / PARTIAL / OPEN, each release, and each ASSUMPTION as VERIFIED / FAILED / OPEN (`settles` column).
