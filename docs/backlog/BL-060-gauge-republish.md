### Why T1 US1 moved 27 / 53 → 36 / 71 (checked before publishing)

The current code was run on the assembled STL of each commit since BL-054 (unit pull, US1 and US2, bag-on and the
governing cradle leg):

| Print | US1 box voxels | US1 bag-on point / band min (MPa/N) | US1 cradle point | US2 bag-on point |
|---|---|---|---|---|
| BL-054 `ef72099` | 135473 | -0.00019 / -0.00060 | -0.00383 | 0.01357 |
| BL-055 `0910c6d` | 143257 | -0.00038 / -0.00081 | -0.00366 | 0.01357 |
| BL-056 `6b0cde1` | 143257 | same as BL-055 | -0.00366 | 0.01355 |
| BL-058 `4f5ff07`, `d494ec8` | 143257 | same as BL-055 | -0.00366 | 0.01336 |

- **The code isn't the cause.** The current code on the BL-054 STL gives 0.00060 x 148.1 x 1.15 / 3860 = 27 µε,
  which is the old line.
- **There was no raster change.** The voxel size (1.0) and GAUGE_TOL (1.5) are unchanged. The bag-on load (444.4 N
  factored, unit [0, -0.964, 0.266]) is unchanged.
- **BL-058 isn't the cause.** The retainers are in the pins (hairpin cross holes) and the US2 counterbore sits
  outside the US1 box. BL-058 changes US2 by -1.5 % and leaves US1 unchanged.
- **The cause is BL-055's grown hip boss.** It is D50, 16 mm deep, for 8 inserts. The voxel difference between the
  BL-054 and BL-055 prints in the US1 box is +8514 voxels at x -6..25, y -49..-33, z 96..145, centred on the boss
  axis (0, -48, 120). That is 93 mm from the gauge. The US1 submodel box reaches the lumbar hub (BOXES, "to the
  lumbar hub"), so the stiffer hub changes how the arm-root bending splits.
- **Why the change is large in percent.** Under the bag-on (-y) pull the US1 gauge sits near a null point. The point
  value goes -7 → -15 µε at 150 lb, and the band minimum, which sets the pass line, goes -0.00060 → -0.00081 MPa/N.
  The same hub change costs the cradle line only 4 %, because the shift is a small fraction of a large value there.
- **Physically it is real**, inside the model's own assumptions (SUB-BC, GAUGE-LOCAL). In absolute terms it is small:
  +9 / +18 µε, which is about the zero drift of a PAHT half-bridge (see "Found, not fixed").
